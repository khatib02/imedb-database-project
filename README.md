# IMEdb - Movie Database & Analytics

## Project Overview
**IMEdb** is an academic project designed to simulate a movie database similar to IMDb. The main goal was to model a relational system capable of storing complex entertainment data and, most importantly, **driving business insights** through SQL analysis.

We built this project from the ground up—starting with **Business Requirements**, moving through data modeling, and finally implementing the database structure and analytical reports.

## Tech Stack & Skills
* **Database:** PostgreSQL
* **Modeling:** Entity-Relationship Diagram (ERD) & Relational Modeling
* **Data Analysis:** Advanced SQL (Joins, Aggregations, Subqueries)

## Analytics Highlights (BI & SQL)
My primary contribution focused on structuring data to enable strategic analysis. Inside the `/sql` folder, you will find queries that answer business questions such as:

* **Global Performance:** Analyzing average ratings and user engagement grouped by **Country**.
* **Genre Metrics:** Detailed statistics (Average, Min, Max ratings) across different movie genres.
* **Studio Productivity:** A View created to track which studios are producing the most content on the platform.
* **User Engagement:** Identifying "Heavy Users" to support potential loyalty strategies.

## Database Structure
The data modeling ensures integrity and supports complex queries:
* **Core Entities:** Movies, Series, Users, Actors, and Directors.
* **Visual Documentation:** You can find the full schema diagram in the `/docs` folder.
